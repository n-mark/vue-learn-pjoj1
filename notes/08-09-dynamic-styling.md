# Динамические стили для иконок

В этой лекции мы рассмотрим, как создавать и управлять динамическими стилями для иконок.

## Динамические стили

Мы обсудили, как изменять размеры и цвета иконок динамически.
Использование props для передачи параметров color и size в компоненты.
Реализация динамических стилей с помощью CSS, используя масштабирование (scale).

## Создание иконок

Создали папку weather для иконок о погоде.
Рассмотрели создание иконок солнца, дождя и облаков в двух размерах (95 и 55) и цветах.
Использовали масштабирование для изменения размера иконки в соответствии с заданным коэффициентом.

## Практическая реализация

Пример с иконкой солнца: задали начальную конфигурацию с дефолтными значениями.
Изменяли fill для цвета, чтобы оно было динамическим.
Применили те же принципы для других иконок, как облака и дождь.

## Оптимизация компонентов

Рассмотрели возможность создания единого компонента, который выбирает и выводит нужную иконку на основе переданных свойств.
Однако оставили компоненты отдельными для простоты и изоляции.

## Тестирование

Завершили тестирование всех иконок в браузере для проверки корректности отображения и масштабирования.
