# Создание центральной панели приложения

В этом упражнении мы создадим центральную панель с фоном и кнопкой для нашего приложения, используя корневой компонент "апп-компонент". Вот структура нашего подхода:

## Создание структуры

Удаляем существующий код из "апп-компонента".
Используем семантический тег <main> для обертки нашего приложения, задаем ему класс "main".

## Стилизация

Для элемента <body> задаем стиль display: grid; place-items: center; для центрирования контента.
Устанавливаем минимальную высоту 100vh для элемента <body>, чтобы контент был по центру вертикально.

## Стили для <main>

Устанавливаем фон
Добавляем паддинг: по вертикали 60px, по горизонтали 50px.
Задаем радиус скругления границ 25px.

## Результат

После применения стилей кнопка находится по центру страницы в элементе <main>.
Это базовая настройка для дальнейшей работы с компонентами.
