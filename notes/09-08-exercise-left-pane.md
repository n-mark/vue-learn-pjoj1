# Вёрстка левой панели интерфейса

В этой лекции мы разбираем процесс вёрстки левой панели интерфейса приложения. Основные этапы:

## Создание контейнера

Мы создаём новый флекс-контейнер для левой панели (PaneLeft.vue) и определяем нужные компоненты: скрипт setup, template и styles scoped.

## Передача данных

Указываем необходимые данные через defineProps, в частности, dayData для отображения выбранной даты.

## Связывание данных

В основном компоненте (App.vue) делаем биндинг dayData и проверяем его правильность через консоль для устранения ошибок.

## Отображение даты и дня недели

Извлекаем dayData.date и преобразуем её в строку формата даты и дня недели.
Отображаем данные с помощью computed для упрощения шаблона.

## Отображение города

Инжектируем city из существующих данных и размещаем его вместе с иконкой локации.

## Добавление иконок погоды

Используем логику weatherCode для выбора соответствующих иконок.
Рассчитываем и корректируем размеры иконок.

## Структурирование окончательной вёрстки

Добавляем отступы, размеры шрифтов и другие стили для элементов.
Настраиваем динамическое обновление информации при изменении данных.

## Итог

Создана функциональная левая панель, способная динамически отображать актуальную информацию о погоде, дате и городе с учётом выбранных настроек.
