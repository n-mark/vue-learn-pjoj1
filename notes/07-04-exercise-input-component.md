# Создание компонента Input

## Цель

Создать отдельный компонент input без логики, сосредотачиваясь на верстке и стилизации.

## Шаги

### Создание Компонента Input

Структура: Используйте script setup и template.
Элемент Input: Добавьте элемент input с классом input.

### Стилизация Input

Основные стили:
Задайте ширину, радиус границ, background, и box-shadow.
Переменные: Используйте переменные для цветов из существующих настроек
Placeholder: Задайте цвет для placeholder через custom-property

Дополнительные свойства:
Уберите border (border: none).
Минимальная высота 53 пикселя.
Шрифт внутри элемента 18 пикселей.

### Использование Компонента

Импортируйте и используйте компонент Input.vue.
Примените стили и размеры из предыдущих шагов.

### Стилизация Группы Input

Создайте группу элементов с классом CityInput.

Flexbox Layout:
Задайте display: flex и gap: 12px.
Задайте фиксированную ширину (например, 260 пикселей).

### Правки и Настройка

Убедитесь, что box-sizing установлен для всех элементов.
Задайте высоту для элементов input и кнопок одинаковую — 53 пикселя.
Организуйте элементы в div с классом CitySelect для упрощения работы с flexbox и выравнивания.

## Итог

Получили компонент input, который располагается корректно, стилизован и готов к дальнейшему добавлению логики. Этот подход обеспечивает единообразный вид и поведение на этапе верстки.
