# Директива v-if в Vue

## Директива v-if

Она позволяет отображать или скрывать части шаблона на основе условий. Чтобы скрыть элементы, нужно добавить директиву v-if с логическим выражением, которое определяет, отображать ли элемент.

## Практическое применение

В примере используется функционал изменения города. Если город редактируется, отображаются элементы ввода и кнопки. Это достигается с помощью v-if и реактивного состояния isEdit.

## Удаление лишнего

Убираются ненужные элементы, чтобы сосредоточиться на важных частях, которые нужно скрывать.

## Использование div и template

Если нет необходимости в дополнительном контейнере div, для объединения элементов можно использовать тег template. Он не отображается на странице, но объединяет элементы для применения v-if.

## Специфика использования template

На верхнем уровне нельзя применять v-if на template. Внутри template нужно использовать директивы, иначе это нарушение синтаксиса.

## Прямое управление элементами

У v-if можно применять непосредственно к отдельным элементам, если требуется скрыть именно один элемент, например, input.
