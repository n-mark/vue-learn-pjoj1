# Использование Composition API в Vue

В этой лекции мы фокусируемся на использовании Composition API в Vue, который является современным и удобным способом написания компонентов. Основные моменты:

## Способы написания компонентов

Composition API: Современный и упрощенный способ. Здесь используется скрипт с атрибутом setup, который исполняется при инициализации компонента.
Option API: Более старый стиль, сложный в записи. Требует экспорта большого объекта с данными, методами и Lifecycle-хуками.

## Преимущества Composition API

Позволяет эффективно управлять состоянием компонентов.
Упрощает доступ к данным через функцию setup.
Не требует экспорта сложных объектов, как в Option API.

## Использование в старых проектах

Если проект старый или на Vue 2, там может применяться Option API.
Необходима консультация с документацией, если нужно использовать старую структуру.

## Возможности смешанного подхода

Можно продолжать использовать оба подхода, но рекомендуется перейти на Composition API.

## Дополнительные ресурсы

Все примеры, связанные с Option API и Composition API, сохраняются в Git-репозитории.
В Vue документации есть переключатель для примеров с разными API.

Основная рекомендация — использовать Composition API для улучшения и упрощения разработки компонентов.
