# Директива v-for в Vue.js

## Введение

v-for: директива Vue.js для вывода списков.
Применение на практике: множественная запись элементов на основе данных.

## Вывод списков

Создание массива: например, ["Антон", "Вася", "Марина"].
HTML структура: используем <ul> для списка и <li> для элементов.

## Применение VIFOR

Формат цикла: v-for="item in items".
Описание: повторение элемента для каждого значения в массиве.

## Ключи в списках

Зачем нужны ключи: для отслеживания изменений (добавление/удаление элементов).

Использование ключей:
Формат: :key="item".
Преимущества: оптимизация производительности, корректная работа с изменениями.
Рекомендация: всегда использовать уникальные идентификаторы (например, ID).

## Индексы в списках

Как получить индекс элемента: запись v-for="(item, index) in items".
Применение индексов: улучшение опыта разработчика, при необходимости манипуляции.

## Работа с объектами

Обход объекта VIFOR:
Формат: v-for="(value, key, index) in object".
Пример объекта: { name: 'Антон', age: 18 }.
Вывод ключей и значений наряду с индексами.

## Примечание

Приоритет директив: v-if проверяется перед v-for.
