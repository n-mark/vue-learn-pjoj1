# Цвета, Custom Properties, градиенты и шрифты

## Цвета и Custom Properties

Определяем основные цвета, которые будут переиспользоваться.
Создаем переменные для цвета фона, основного цвета (primary) и их инверсий (например, для темной темы).
Прописываем все цвета через Custom Properties, чтобы упростить изменение стиля в будущем.

## Градиенты и шрифты

Создаем переменные для градиентов, учитывая возможность инверсии при ховере.
Подключаем шрифт Montserrat через Google Fonts, определяем его как основной для body.

## Примечания по структуре кода

Для удобства переменные выносятся на уровень body.
Сочетание color-bg и color-fg используется для настройки фона и текста.

## Подключение шрифта

Добавляем шрифт Montserrat на все страницы приложения.
Очищаем лишние шрифты и фокусируемся на одном основном.

## Итог

Базовая стилизация готова, что позволяет приступить к разработке компонентов на Vue с уже определенными основными стилями.
