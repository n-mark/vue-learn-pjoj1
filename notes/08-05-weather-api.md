# Работа с состоянием и API-запросами

## Состояния

App.vue: Хранит текущий сохраненный город.
CitySelect: Хранит город, который пользователь вводит.
Решение: Оставляем только одно состояние для оптимизации, чтобы избежать избыточности.

## Запрос данных

Запрос следует делать в функции GetCity при нажатии на кнопку "Сохранить", чтобы избежать лишних запросов при каждом изменении в поле ввода.
Для начальной загрузки используется Lifecycle Hooks, чтобы имитировать выбор дефолтного города.

## API-запрос

Определяем API Endpoint и используем fetch для запроса данных.
Конструируем параметры запроса, включая язык и ключ API.
Конвертируем ответ в формат JSON и выводим его для отладки.

## Отображение данных

На событие выбора города подписан основной компонент, который обновляет данные и отображает их.
При изменении города, новое состояние передается и отображается.

## Обработка ошибок

Необработанные ситуации включают некорректные данные или ошибки запроса; запланировано добавить обработку ошибок и состояния загрузки.
