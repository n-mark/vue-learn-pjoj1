# Очистка стилей и компонентов

## Удаление лишнего

- Удаляем все ненужные стили из файла `style.css`, оставляя только настройки для сглаживания шрифтов.
- Удаляем глобальные готовые стили, чтобы начать проект с нуля.
- Удаляем папку с компонентами, пока она не понадобится.

## Структура проекта

- **script**: Раздел, где будет JavaScript-код, управление состоянием и т.д.
- **template**: Содержит HTML-шаблон, показывающий, как будут отображаться данные.
- **styles scoped**: Стилевые правила, применяющиеся только к текущему компоненту.

## Отображение базового шаблона

- Пример добавления текста «Привет» в шаблон для проверки отображения.
- Возможность добавления HTML-структуры (`main`, `header`, `footer`) для демонстрации динамического обновления страницы через Live Server.

## Последующие шаги

- Финальная очистка и подготовка проекта к более сложной настройке перед углублением в Vue.
- Убедиться, что среда разработки обновляется автоматически, чтобы изменения сразу отображались в браузере.
