# Создание компонента карточки дня (DayCard)

В этом видео мы создаем компонент карточки дня (DayCard) для отображения информации о погоде. Вот основные шаги процесса:

## Создание компонента

Создайте компонент DayCard.vue с шаблоном, скриптом и стилями.
Убедитесь, что стили изолированы (scoped).

## Разметка карточки

Используйте <div> с классом DayCard для контейнера карточки.
Добавьте отступы: padding 20px 24px.
Задайте фон: background-color.

## Добавляем содержимое

Подключите необходимые свойства (props): иконку, температуру и дату.
Используйте weatherCode для выбора иконки погоды.

## Работа с данными

Используйте props для получения иконки (солнце, дождь, облака).
Преобразуйте дату с помощью toLocaleDateString для нужного формата и отображения.

## Стилизация

Центрируйте элементы с помощью align-items: center и justify-content: center.
Задайте отступы между элементами: gap: 15px.
Задайте шрифт и цвет текста

## Добавление стилей для текста

Определите классы для даты и температуры и установите размеры шрифта.

## Настройка внешнего вида

Используйте закругление углов и тени (border-radius, box-shadow).
Замените <div> на <button>, если это кликабельный элемент, и уберите границы.

## Функциональность ховера

Добавьте стилевые изменения при ховере для визуального эффекта.
