# Рефакторинг с Provide/Inject

## Проблема в текущем приложении

Прямое использование emit для передачи данных между компонентами.
Данные проходят через лишние компоненты.

## Решение с использованием Provide/Inject

Убрать все emit и заменить их механизмом Provide/Inject.

## Шаги рефакторинга

Удалить defineEmit и функции emit из компонента CitySelect.
Перенести реактивное состояние из CitySelect в корневой компонент App.
Создать provide для города (City) в корневом компоненте App.
В компоненте CitySelect использовать inject для получения значения города.

## Работа с Input

Ввести реактивное состояние InputValue с использованием ref.
Задать InputValue начальным значением инжектированного города.
Использовать v-model для привязки InputValue к элементу Input.

## Обработка сохранения города

При изменении города в Input и нажатии клавиши "сохранить", обновить значение города.
Использовать watch для отслеживания изменений города и выполнения API-запроса getCity.

## Первоначальное состояние и загрузка данных

Использовать onMounted для первого вызова GetCity с начальным состоянием города.

## Преимущества

Устранение избыточности передачи данных через компоненты.
Централизованное управление состоянием.

## Детали реализации

Обратная связь в случае изменения состояния теперь управляется централизованно.
Ошибки компиляции (типа с ref) требуют осторожного подхода и проверки на этапе разработки.

Этот рефакторинг улучшает модульность и читаемость кода, обеспечивая более надежное управление данными через использование Provide/Inject.
