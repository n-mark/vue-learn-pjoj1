# Стилизация кнопки в Vue-компоненте

## Создание стиля кнопки

Используем тег `<style>` для добавления CSS к нашей кнопке.
Внутри `<style>` пишем стили для кнопки, подобно обычному CSS.

## Изоляция стилей

Используем атрибут scoped в теге `<style>`, чтобы стили применялись только к текущему компоненту.
Это предотвращает утечку стилей на другие элементы.

## Добавление стилей к классу

Задаем классы и стили: убираем границу, задаем радиус, градиент, padding, шрифт и цвет.
Пример: класс .button, где стилизуем границу, шрифт и цвет.

## Предотвращение утечки стилей

Показываем, что без scoped стили могут применяться к другим элементам с тем же классом.
С scoped стили применяются только к целевому компоненту.

## Дополнительные стили

Добавление курсора и состояния наведения (:hover) для кнопки.
Меняем градиент на :hover.
