# Динамическая передача данных

Динамическая передача данных: Вместо жестко заданных значений, данными можно оперировать динамически, используя переменные или константы.

Пример с константами: Определяются две константы для демонстрации - label (влажность) и stat (90%).

Использование v-bind:
v-bind можно использовать для привязки значений переменных к атрибутам.
Сокращенная запись через двоеточие (:) позволяет передавать переменные вместо строк.

Работа с объектами:
Можно создавать объекты с нужными атрибутами и передавать их полностью с помощью v-bind.
Например, объект data с ключами label и stat передается целиком через v-bind="data".
