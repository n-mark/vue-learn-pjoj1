# Использование JavaScript выражений в шаблонах Vue.js

В этой лекции мы рассмотрим, как использовать JavaScript выражения в шаблонах Vue.js.

## Встраивание JavaScript в шаблоны

Вы можете использовать любые валидные JS выражения прямо в шаблонах. Например, можно выполнить простую арифметическую операцию: в теге footer написать {{ 10 + 20 }} для отображения результата (30) в браузере.

## Тернарные операторы

Можно использовать тернарные операторы для простых логических проверок. Например, если у вас есть константа isAdmin, равная true, вы можете установить отображение текста в зависимости от ее значения: {{ isAdmin ? 'Admin' : 'Not Admin' }}.

## Динамика в атрибутах

Вы можете динамически назначать значение атрибуту, используя привязку (binding). Например, для динамического класса: :class="'color-' + color". Если color будет равно 'blue', то конечный класс будет color-blue.

## Использование шаблонной строки

Можно использовать шаблонные строки для формирования сложных выражений или значений внутри атрибутов.

## Итог

Все шаблонные выражения преобразуются в строку, которая затем выводится. Это позволяет гибко управлять отображением данных в компонентах Vue.js.
