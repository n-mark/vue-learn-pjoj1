# Unwrap в шаблонах Vue

## Unwrap в шаблонах

Автоматическая развертка (unwrap) реактивного состояния происходит в шаблоне.
Это позволяет работать с реактивными значениями без явного указания .value.

## Взаимодействие с вложенными реактивными состояниями

В реактивных объектах, содержащих другие реактивные состояния, автоматическая развертка происходит без использования .value.
Пример: реактивный объект Counter, содержащий count, изменяется без необходимости использовать .value.

## Ограничения автоматического Unwrap

Не все структуры поддерживают автоматический unwrap:
В Map и array, обернутые в реактив, автоматическая развертка не происходит, нужно использовать .value.
Вложенные ref внутри объекта требуют явного обращения через .value для изменений.

## Практическое применение

Без unwrap в шаблоне можно работать с верхнеуровневыми реактивными объектами.
Для обращения к вложенным значениями создавайте отдельные переменные, например:

```javascript
const id = obj.id;
```
Используйте id без .value
