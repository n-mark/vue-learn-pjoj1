# Создание первого компонента в Vue

## Создание компонента

Перейдите в папку с компонентами.
Создайте новый файл компонента с расширением .vue, например, Button.vue.

## Структура компонента

Каждый .vue файл подразумевает объединение стилей, скрипта и шаблона в одном файле.

Основные составляющие компонента:

Скрипт (script): укажите атрибут setup, чтобы в процессе сборки сформировалась функция setup для установки данных.
Шаблон (template): определите, как компонент будет отображаться. Например, завернуть содержимое в тег `<button>`.

## Импорт и использование в приложении

Импортируйте компонент в главный файл приложения (App.vue).
Используйте стандартный метод импорта: import Button from './components/Button.vue';.
Добавьте компонент в шаблон вашего приложения, используя его имя как HTML тег.

## Преимущества компонентного подхода

Позволяет создавать приложение из независимых строительных блоков.
Упрощает управление зонами ответственности, выделяя функциональность в отдельные компоненты.
