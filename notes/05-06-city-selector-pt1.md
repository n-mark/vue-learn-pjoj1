# Упражнение: компонент CitySelect

## Цель упражнения

Разработка компонента для изменения города.
Изучение работы с событиями на примере этого компонента.

## Компонент CitySelect

Содержит кнопку «Изменить город».
Содержит поле ввода и кнопку «Сохранить».
Стилизация на данном этапе не рассматривается.

## Структурирование компонента

Создайте новый компонент CitySelectView.
Используйте script setup и template для размещения элементов.
Импортируйте необходимые кнопки и иконки.

## Шаблон компонента

Отобразите кнопку «Изменить город».
Добавьте кнопку «Сохранить» и поле ввода.

## Стилизация

Настройте текстовый стиль так, чтобы текст выводился в верхнем регистре (uppercase).
