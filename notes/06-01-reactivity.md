# Реактивность и хранение состояния в Vue

В этой лекции мы обсуждаем реактивность и хранение состояния в Vue-приложениях.

## Примеры и ошибки

Изначально продемонстрировано, что сохранение состояния в обычной переменной не работает в Vue.
Показано, что если пытаться отображать данные таким образом в UI, изменений не будет видно.

## Механизмы реактивности

### Vue 2

Основана на Defined Property.
Использует getter и setter для отслеживания изменений.
Проблемы: медленная работа с большими вложенными состояниями и динамическими свойствами.

### Vue 3

Использует современный механизм Proxy.
Позволяет эффективно подписываться на изменения свойств.
Обеспечивает производительность и удобство работы с react-программами.
Преимущество: нет проблем с вложенностью, оборачивает в прокси только при необходимости.

## О Proxy

Функции:
track — для чтения.
trigger — для установки.
Прокси обеспечивает отслеживание изменений и триггерит обновления шаблона и сайд-эффекты.

## Заключение

Vue 3 предлагает более совершенный механизм реактивности через прокси по сравнению с Vue 2, что улучшает производительность и удобство работы. В дальнейшем рассмотрен пример работы с прокси в чистом JavaScript.
