# Основы ref в Vue

## Основы ref

ref импортируется из Vue и используется для создания реактивных переменных.
ref работает как с примитивными типами (строки, числа), так и с объектами.
Для доступа к значению через ref нужно использовать .value.

## Использование в шаблонах

В шаблонах Vue автоматически обрабатываются значения REF без необходимости явного обращения к .value.
Прокси-механизм под капотом позволяет работать с состоянием как с объектом.
