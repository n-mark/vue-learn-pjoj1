# Улучшение проекта: динамические метрики по выбранному дню

## Задача улучшения проекта

Цель: добавить отображение влажности, облачности и ветра для выбранного индекса, а не только текущего дня.
Заменить облачность на вероятность дождя (daily chance of rain), так как облачность отсутствует в данных.

## План действий

Для реализации изменений нужно работать с компонентом compute, который отвечает за статические даты.
Вместо current использовать forecast и использовать выбранный индекс (active index).
