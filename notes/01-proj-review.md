# Вводный обзор проекта на Vue

В этом вводном обзоре проекта на Vue рассмотрим структуру и зависимости проекта, а также запустим его в Dev режиме.

## Структура файлов

- **.vscode**: Содержит конфигурации для Visual Studio Code, включая рекомендованные расширения
- **node_modules**: Хранит все зависимости проекта, установленные с помощью NPM.
- **public**: Для статических ассетов, например, SVG изображений.
- **src**: Основная директория с кодом проекта, содержащая ассеты, компоненты и корневое приложение Vue.
- **main.js**: Создает и подключает приложение Vue.
- **.gitignore**: Список файлов и директорий, игнорируемых Git.
- **index.html**: Стартовая страница с корневым элементом и подключенным скриптом main.js.

## Зависимости

- Основная зависимость – **Vue**
- Dev-зависимости: **Vue.js** и плагин для сборки на основе **Rollup**.

## Запуск проекта

1. Открыть терминал, очистить его и запустить скрипт `npm run dev`.
2. Приложение стартует на `localhost:5173`.

Видимое приложение с базовым счётчиком, стилями и логотипом Vue.
