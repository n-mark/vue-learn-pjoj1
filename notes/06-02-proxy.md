# Прокси в JavaScript

## Что такое прокси

Прокси предоставляют контроль над поведением объектов.
Они позволяют отслеживать изменения свойств объекта через методы-хендлеры, такие как get и set.

## Создание прокси

Для создания прокси используется конструктор Proxy, который принимает два аргумента:
целевой объект, свойства которого мы хотим отслеживать
объект-хендлер с методами get и set.

## Работа методов get и set

get(target, prop, receiver): вызывается при чтении свойства.
set(target, prop, value, receiver): вызывается при изменении свойства.
Эти методы позволяют добавить дополнительную логику при доступе или изменении данных.

## Пример использования

Создаем объект user с именем.
Через прокси следим за изменениями имени.
При чтении и изменении имени можно выполнять дополнительные действия (side effects), такие как логирование.

## Практическое применение во Vue.js

В рамках Vue прокси помогают в реализации реактивности.
Например, при изменении данных компонента Vue может автоматически обновить шаблон.
