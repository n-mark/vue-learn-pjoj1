# Коммуникация между компонентами

Коммуникация между компонентами: Компоненты в приложении должны обмениваться данными, чтобы быть универсальными и не дублировать код.

Передача данных через пропсы: Для передачи данных между компонентами используются пропсы (properties). Это помогает корневому приложению передавать данные, такие как, например, влажность или процент, которые необходимо отобразить.

Объявление доступных свойств: Используйте функцию defineProps, чтобы объявить свойства, которые компонент принимает. Примеры свойств: label и stat.

Использование пропсов: Пропсы можно использовать для отображения данных внутри компонента. Это позволяет легко мультиплицировать компонент с различными данными.

Деструктуризация пропсов: В Vue 3.5 появилась возможность деструктурировать пропсы для упрощения их использования.

Типизация пропсов: Вместо массива можно использовать объект для явного указания типов свойств (например, string). Это помогает избежать ошибок и не требует TypeScript.

Указание значений по умолчанию: Можно задать дефолтные значения для пропсов на случай, если они не переданы.

Динамические данные: Лекция готовит к обсуждению передачи динамических данных в компоненты, что является следующим шагом.
