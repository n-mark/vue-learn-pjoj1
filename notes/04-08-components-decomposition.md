# Понимание компонентов

## Понимание компонентов

Компоненты — это переиспользуемые строительные блоки приложения.
Показатель для выделения компонента: его использование в нескольких местах приложения.

## Пример компонентов

Кнопка: уже реализована и используется повсеместно.
Лейбл со значением (Stat).
Карточка дня (DayCard).
Значки погоды (WeatherIcon).

## Неповторяющиеся части

Элементы, которые встречаются уникально, стилизуются непосредственно на месте, без оформления в компоненты.

## Логическая структура приложения

Корневой компонент: содержит основные части приложения.
Левая панель (LeftPanel): пример глупого компонента, отображающего данные.
Список карточек: выделяется как list-days с логикой переключения.

## Выделение атомарных компонентов

CitySelect: кнопка, которая трансформируется в input для выбора города.
Возможность дополнительных компонентов для блоков статистики.

## Концепция строительства приложения

Правильно выделенные компоненты облегчают понимание структуры и последующее обслуживание приложения.
Строение приложения представляет собой дерево компонентов, вложенных друг в друга.
