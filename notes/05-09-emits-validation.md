# Валидация событий через defineEmits

## Запись события

Вместо массива используем объект, где ключ — название Emit события (например, SelectCity).
Если валидатор не нужен, просто используем null как значение.

## Валидация

Объявляем валидационную функцию как метод объекта, который принимает payload (аргумент события) и возвращает true или false.
Пример: return payload ? true : false — простая проверка на наличие значения.

## Логи и предупреждения

Можно добавить логирование для отслеживания входящих данных: console.log("ValidatingPayload", payload).
Если валидация не пройдена, Vue выдаст предупреждение, указывая на неправильное использование события.

## Обратная связь

Если валидация провалена, отправляется предупреждение разработчику.
При правильных данных предупреждение исчезает.

Эта методика позволяет эффективно валидировать события и предупреждать разработчиков о возможных ошибках в коде.
