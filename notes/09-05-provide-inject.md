# Props Drilling и решение через Provide/Inject

## Props Drilling

Props Drilling: необходимость передачи данных (пропсов) между компонентами, которые не используют эти данные напрямую.
Проблема возникает, когда нужно передать значение от верхнего компонента к нижнему, через несколько промежуточных компонентов, которые не используют это значение.

## Пример проблемы

Дерево компонентов: имеется App, PaneRight, Select, и значение из App нужно передать в Select.
PaneRight не использует значение, но вынуждено его передавать.

## Решение: Использование Provide и Inject

Provide: функция для предоставления данных на высокоуровневом компоненте, где данные генерируются.
Inject: функция для получения данных в низкоуровневом компоненте, которому данные нужны.
Позволяет избежать ненужной передачи данных через промежуточные компоненты.

## Практическая реализация

### Provide

Импортировать функцию Provide.
Использовать Provide в компоненте App с нужным значением и ключом.
Например, provide('key', value).

### Inject

Использовать Inject в компоненте Select.
Получить значение через Inject по ключу, например, const value = inject('key').

## Работа с реактивными состояниями

Можно проводить как статичное значение, так и реактивное состояние.
При передаче реактивного состояния следует использовать value.value для его получения.

## Пример реактивного состояния

Использование Provide для передачи реактивного состояния ActiveIndex.
Inject в Select позволяет следить за изменениями в состоянии.

## Выводы

Использование Provide и Inject упрощает структуру приложения, исключая ненужные промежуточные передачи пропсов.
Позволяет эффективно связывать компоненты и управлять их состояниями без сложного props drilling
