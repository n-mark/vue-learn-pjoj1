# Двухсторонняя связь (two-way binding) в компоненте Input

## Определение цели

Мы хотим, чтобы данные, введенные в инпут, передавались вверх и могли обновляться извне. В результате любое изменение в инпуте будет сразу отражено в компоненте и наоборот.

## Настройка emit

Для уведомления компонента о введенных данных мы используем defineEmit. Это позволит отправлять события обновления значения при каждом вводе.

## Обработка события ввода

При каждом вводе мы инициируем событие update:value с текущим значением инпута. Это делается через встроенное событие input.

## Метод обработки события

Создаем функцию updateCity, которая будет обрабатывать обновляемые значения и выводить их, например, в консоль. Функция назначается обработчиком для события update:value.

## Реактивное состояние

Создаем реактивное состояние city для хранения текущего значения ввода. Значение обновляется при каждом изменении инпута.

## Двухсторонняя связь (two-way binding)

Используем defineProps, чтобы получить значение по умолчанию (например, "Moscow").
Привязываем value проп к инпуту, используя директиву v-bind.
Теперь при входе новых данных, они становятся доступными для редактирования, и изменения передаются обратно в компонент.

## Результат

Когда меняется состояние инпута, изменяется и состояние компонента, и наоборот. Это обеспечивает синхронизацию между вводом и компонентом.

## Ограничения и улучшения

Созданное решение на данный момент не оптимально, и дальнейшая оптимизация возможна при помощи v-model. Короткие пути (shortcuts) будут рассмотрены позже.
