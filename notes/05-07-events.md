# Обработка событий в JavaScript и Vue.js

## Обработка событий в JavaScript

В обычном JavaScript для обработки событий, например, нажатия кнопки, используется атрибут onclick.
Можно задать функцию для вызова при нажатии, например, console.log("тест") для отображения сообщения в консоли.

## Проблемы с глобальным пространством

Если функцию, такую как log, определить внутри одного компонента, она не будет доступна в глобальной области, и это вызовет ошибку, если пытаться её вызвать через onclick.

## Компонентный подход во Vue.js

Во Vue.js привязка событий происходит через синтаксис с "собачкой" (@), например, @click, который заменяет стандартное onclick.
Можно вызывать функции, объявленные локально в компоненте Vue.js, без их глобального объявления.

## Создание функции в Vue.js

Функции в Vue.js можно объявлять как обычные функции или стрелочные, например, log или logArrow.
Эти функции можно вызывать в реакцию на событие: @click="log".

## Работа с событиями

Используйте @click, @change и другие Vue-обработчики событий для реакции на пользовательские действия.
