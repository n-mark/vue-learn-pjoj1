# Обработка ошибок при запросе данных о городе

## Цель

Научиться обрабатывать ошибки в приложении, когда невозможно получить информацию о городе.

## Этапы

### Определение ошибки

При запросе данных о городе, если возвращается статус-код 400, это означает ошибку.
По коду ответа можно определить иные ошибки, такие как баланс не найден, но в данном контексте важна обработка ошибки "город не найден".

### Создание реактивного состояния

Создайте состояние error, чтобы хранить информацию об ошибке.
Используйте error.value, чтобы сохранить полученные данные ошибки с помощью await res.json().

### Создание компонента для отображения ошибки

Назовите компонент Error.vue.
Он будет принимать и отображать сообщение об ошибке, используя defineProps.

### Интеграция компонента

Импортируйте и используйте компонент Error в основном шаблоне приложения.
Передайте компоненту нужные данные из состояния Error.

### Стилизация компонента

Используйте CSS для стилизации ошибки, установив размеры шрифтов, отступы, цвета фона и границы.
Примените margin-top и margin-bottom для позиционирования.

### Корректировка текста ошибки

Создайте карту (Map) ошибок, чтобы сопоставить полученные коды ошибок с пользовательскими сообщениями.
Используйте computed для отображения сообщений на нужном языке (русском, в данном случае).

### Проверка и тестирование

Проверьте отображение ошибки при различных вводах.
Убедитесь, что ошибки обрабатываются корректно и отображаются в ожидаемом виде.
