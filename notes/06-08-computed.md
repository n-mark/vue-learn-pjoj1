# Вычисляемые свойства (computed) в Vue

## Что такое вычисляемые свойства?

Это свойства, которые рассчитываются на основе других реактивных данных.
Их цель — уменьшить логику внутри шаблонов и сделать код более чистым и структурированным.

## Как они работают?

Вычисляемые свойства автоматически кэшируются, и пересчитываются только если изменяются их зависимости.
Например, если у нас есть данные влажности, мы можем создать вычисляемое свойство, которое будет превращать эти данные в форму с процентами, без дополнительных расчетов в шаблоне.

## Преимущества использования

Повышение производительности за счет кэширования.
Более чистый код, так как логика вывода данных выносится из шаблонов в скриптовую часть.

## Особенности

Вычисляемые свойства не пересчитываются, если нет реактивных изменений.
В новой версии Vue.js (3.4) вычисляемые свойства могут принимать предыдущее значение, что дает возможность базироваться на них для нового расчета.

## Практическое применение

Создаем реактивные состояния с помощью ref.
Используем computed для построения вычисляемых свойств.

Этот подход делает ваше приложение более эффективным и структурированным.
